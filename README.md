🚀 Animated Navbar with Toggle Functionality
This project features an animated navbar built using HTML and CSS, designed to offer a dynamic and interactive user experience. The navbar includes an X icon that, when clicked, opens the menu, and when clicked again, it closes. This toggle functionality provides an intuitive and engaging way to interact with the menu.

The design is smooth, with animations that enhance the transition between open and closed states, ensuring a pleasant user experience.

🌟 Features
✔ Toggle Menu – Click the X icon to open or close the navbar, providing an interactive navigation experience.
✔ Smooth Animations – Transitions and animations add a dynamic feel when the menu is opened or closed.
✔ User-Friendly Interaction – Simple and intuitive navigation for users with clear visual feedback.

🔧 Technologies Used
HTML5
CSS3 (Including Animations and Transitions)

🚀 How to Use
1️⃣ Clone the repository:
git clone https://github.com/emineugurlu/Navbar.git

2️⃣ Navigate to the project folder:
cd Navbar

3️⃣ Open index.html in a browser to view the animated navbar in action.
